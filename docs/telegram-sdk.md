# Библиотека Telegram Mini Apps

`frontend/public/vendor/telegram-web-app.js` — неизменённая копия официальной библиотеки из https://telegram.org/js/telegram-web-app.js, полученная 29 октября 2026 года.

SHA-256: `124bdff7ba3fe86c8ba5143467afec21e020405e74abdb92cfdda6c0ee3b5908`.

Библиотека загружается с домена Mini App перед запуском React, чтобы вход не зависел от доступности `telegram.org` на устройстве сотрудника. При ошибке загрузки приложение предлагает повторить попытку. Внешний SDK автоматически не подменяется: обновление этой копии выполняется явно вместе с проверками приложения.

Данные запуска берёт сама библиотека Telegram. Сервер по-прежнему проверяет подпись и срок действия `initData`; наличие Android-моста, платформы или данных пользователя без подписи не предоставляет доступ.

Документация: https://core.telegram.org/bots/webapps#initializing-mini-apps.
