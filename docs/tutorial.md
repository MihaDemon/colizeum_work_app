# Интерактивное обучение

В Mini App обучение доступно через **«Ещё → Обучение»**. При первом входе
администратора или управляющего появляется необязательное приглашение. Кнопка
«Позже» скрывает его на этом устройстве для данного аккаунта и роли.

Администратор открывает учебную смену, отправляет задачу с фото, исправляет
результат после возврата, учитывает расход, отмечает приход уборщицы, закрывает
смену и находит отчёт. Обучение администратора доступно всем ролям.
Управляющий проверяет смену, назначает задачу, просматривает отправку, возвращает
её с причиной, принимает исправление и находит свои личные задачи.

Единое обучение «Работа управляющего» доступно управляющим и суперпользователям.
Оно последовательно проводит через обычные задачи, автоматические задачи
(создание, приостановка и возобновление шаблона), график смен (ручное назначение,
черновик 2/2 и восстановление версии), затем раздел «Уведомления».
В последних двух упражнениях пользователь выключает «Расходы из кассы»,
сохраняет настройку, затем включает её обратно и снова сохраняет. Смена
переключателя без сохранения не завершает упражнение. Все настройки учебные.

Сценарий администратора содержит семь упражнений, управляющего — четырнадцать.
Все разделы управляющего используют один прогресс с возобновлением и возвратом.
«Далее» доступно после успешного действия. «Назад» восстанавливает состояние
перед предыдущим упражнением.
Прогресс сохраняется в localStorage отдельно для аккаунта, роли и версии
обучения; синхронизации между устройствами нет. При недоступном хранилище
обучение работает в текущем окне и сообщает, что прогресс не сохранён.
Незаполненные формы между посещениями не сохраняются.

## Изоляция

Обучение использует существующий `Workspace` с локальным обработчиком команд.
Живой `LiveWorkspace` на время обучения размонтирован, его опрос сервера отменён.
Учебные действия не обращаются к API. Формы автоматических задач, графика и
уведомлений в соответствующих упражнениях используют локальный адаптер вместо
сетевых запросов; неподдерживаемые действия отклоняются. Оборудование, персонал
и служебные настройки недоступны в обучении. Раздел «Уведомления» открывается
в заключительной части обучения управляющего; личные настройки настоящего
аккаунта остаются прежними.
Входящие ссылки на реальные записи не применяются к учебному экрану.
При выходе живой экран заново получает данные сервера.

При фокусе поля или уменьшении видимой области из-за клавиатуры подсказка
перемещается в компактную строку сверху. Нижняя навигация скрывается на время
ввода. После завершения ввода подсказка возвращается; восстановление слегка
отложено, чтобы не переместить кнопку сохранения во время нажатия.

## Локальный просмотр

```sh
cd frontend
npm run dev
```

- Администратор: `http://localhost:5173/?tutorial=admin`
- Управляющий: `http://localhost:5173/?tutorial=manager`

Эти ссылки открывают только учебный экран без авторизации **в режиме разработки**.
В production параметр `tutorial` не обходит обычный вход через Telegram.

## Проверка

```sh
cd frontend
npm test
npm run build
npx playwright test tests/e2e/tutorial.spec.ts
npx playwright test tests/e2e/app.spec.ts --grep 'training entry'
```

Браузерные проверки проходят оба сценария целиком на desktop и mobile, проверяют
отсутствие любых запросов к API, возобновление, возврат к предыдущему упражнению,
входящие ссылки, недоступность хранилища, вход из настоящего рабочего интерфейса
с имитацией Telegram и восстановление опроса после выхода.
Клавиатуру телефона, физические safe area и системную кнопку Telegram нужно
дополнительно проверить на реальном устройстве.

## Учебное изображение

`frontend/public/tutorial/workstation.png` создано встроенным инструментом
Imagegen. Это вымышленное фото для упражнения, не свидетельство реальной работы.
Фото используется повторно в полях отчёта; в реальной смене нужны снимки по
названиям полей. Итоговый запрос генерации:

> Use case: photorealistic-natural. Asset type: a sample evidence photo for a staff
> training tutorial in a computer club management app. Generate a realistic modest
> phone photograph of one clean gaming workstation: black desk, monitor with blank
> dark screen, keyboard, mouse on a large dark mouse mat, headset, chair partially
> visible. Viewed from standing height at slight angle, practical even room
> lighting, no people, no brands, no text, no watermarks. This is an ordinary task
> completion photo, not an advertisement. Landscape 4:3 composition. Save the
> generated asset for use in this local project.
